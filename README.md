# Traditional Boat Detection using YOLOv8

## Overview

This project focuses on detecting traditional boats of Bangladesh using a custom-built dataset and deep learning techniques. The objective was to develop an object detection model capable of identifying different types of local boats in real-world conditions.

## Contribution

* Contributed to dataset creation and annotation using Roboflow
* Performed data preprocessing and augmentation
* Trained and evaluated object detection models using YOLOv8
* Conducted experiments to improve model performance

## Dataset

Dataset available on Roboflow Universe:
https://universe.roboflow.com/dip-abbd6/traditional-boats-of-bangladesh

Note: This dataset was created collaboratively, and I was involved in annotation and preparation.

## Technologies Used

* Python
* YOLOv8 (Ultralytics)
* OpenCV
* Roboflow
* Google Colab

## Methodology

* Dataset loading and preprocessing
* Data augmentation
* Model training and validation
* Performance evaluation

## Results

* Achieved real-time object detection capability
* Successfully detected multiple categories of traditional boats

1. Open the notebook in Google Colab
2. Install dependencies:
